# Python & Machine Learning Fundamentals

My weekly notebooks while learning Python, NumPy, visualization, and OOP.

## Contents

- `week1_python_fundamentals.ipynb`: Python basics (functions, loops, sigmoid, predictions)
- `week2_numpy_visualization_OOP.ipynb`: coming soon

## How to run

1. Clone the repo
2. Install Jupyter: `pip install jupyter numpy matplotlib`
3. Open the notebooks in VS Code or run `jupyter notebook`
